# NETworker для DLE 21

Адаптивный светлый шаблон для новостного сайта или онлайн-журнала на **DataLife Engine 21.0**. Версия сборки — **1.0.0**. Автор адаптации — **The88788.com**.

## Возможности

- Карусель публикаций с прокруткой пальцем и кнопками.
- Лента новостей, категории и обычная постраничная навигация.
- Обложки из поля `poster`, статья и связанные публикации.
- Боковая колонка: категории, популярные статьи, теги, календарь, комментарии и опрос.
- Штатные формы поиска, входа, регистрации, профиля, комментариев, избранного и личных сообщений DLE.
- Локальные шрифты, один CSS и один JS шаблона.

Предусмотрена одна светлая тема. Тёмной темы и автоматической подгрузки следующей страницы нет. Серверные модули сторонних разработчиков для работы шаблона не требуются. Доступность отдельных действий определяется настройками DLE и пользовательских групп.

## Изменения адаптации

Исправлены теги и параметры DLE, ссылки навигации, мобильное меню и поиск. Устаревшая карусель заменена нативной прокруткой. Исправлены диалоги входа и профиля, конфликт списка комментариев с редактором и горизонтальное переполнение. У изображений зарезервировано место, кнопки карусели включены в исходный HTML. Неиспользуемые файлы и стили удалены из распространяемой сборки.

## Установка

Скопируйте `NETworker` в `templates/`, выберите шаблон в настройках DLE 21.0 и очистите кеш. Обложки используют необязательное поле `poster` типа «Изображение». Подробности — в [INSTALL.md](INSTALL.md).

Архив не содержит CMS, базы данных, демонстрационных материалов или данных авторизации. Совместимость проверена с DLE **21.0**; другие версии не заявляются.
